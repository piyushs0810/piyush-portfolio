## Overview

I'm an Electrical and Electronics Engineering student at the National Institute of Technology Goa, interested in machine learning, software development, and understanding the engineering behind the products I build.

This portfolio brings together my projects, technical interests, and learning journey in one place.

Rather than relying on visual complexity, the design emphasizes typography, spacing, contrast, and purposeful interactions.

## Features

- **Monochrome design:** A minimal black-and-white visual identity with restrained details.
- **Bold typography:** Large headings and clear visual hierarchy.
- **Responsive layout:** Designed to work across desktop and mobile screens.
- **Subtle animations:** CSS transitions and entrance animations for a more engaging experience.
- **Scroll interactions:** Elements reveal themselves as they enter the viewport.
- **Interactive project cards:** Hover effects that bring attention to individual projects.
- **Animated ticker:** A moving strip highlighting engineering and technology interests.
- **Contact section:** Quick access to my professional profiles.
- **Custom favicon:** A personalized browser-tab icon.
- **Accessibility considerations:** Keyboard focus styles and reduced-motion support.

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project.

### 1. Clone the repository

```bash
git clone https://github.com/piyushs0810/piyush-portfolio.git
```

### 2. Enter the project directory

```bash
cd piyush-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local address printed in your terminal to view the website.

### 5. Build for production

```bash
npm run build
```

Astro generates the production-ready website in the `dist/` directory.

### 6. Preview the production build

```bash
npm run preview
```

This lets you check the production build locally before deploying it.

## Design Approach

The visual direction is built around a few principles:

- **Less, but intentional:** Every element should serve a purpose.
- **Typography first:** Large headings establish personality without unnecessary decoration.
- **Motion with restraint:** Animations should enhance the experience rather than distract from the content.
- **Clarity over complexity:** Navigation, project information, and contact links should remain easy to find.
- **Responsive by design:** The layout should remain usable on smaller screens.
